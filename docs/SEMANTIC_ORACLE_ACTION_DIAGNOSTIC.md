# Semantic routing diagnostic after initial-anchor CF recovery

Initial-anchor final200 CF completed all180 episodes with immutable weights, including the evaluation-only power-interruption recovery. Ten-task macro CF is noERAF28.333%, FGonly26.667%, ERAFonly31.667%, ERAF+FG23.333%; strongest archived control remains35%. This recipe did not meet the objective.

This experiment performs zero optimizer updates. It compares each of the actual ERAFonly and ERAF+FG final200 models on identical expert states under learned semantics, privileged semantic routing, whole ERAF disabled, and a learned repeat. All use the existing deployment wrapper, seed42, ten denoising steps, and24 executed action positions. Neither reference actions nor future images enter inference. Errors are normalized masked action MSE against the stored expert; this is not CF success.

Selection is fixed without model outputs: left-placement, RGB-ranking, empty-cup and pillbottle; demo_clean; lowest one training and two replay_holdout scene seeds per task. Use initial and middle cached target frames. The old two tasks have initial-only holdout caches, so their holdout contributes initial states only, producing20 observations per model. Require task-scene split isolation. FG corrective rows are excluded because their temporal phase labels are explicitly invalid. The intervention includes masks, positions, relations, goal anchors, truth and existing expert-trajectory phase annotations. Invisible mask roles may retain predicted attention in the production API. This is neither a pure geometry intervention nor independently verified perfect temporal truth.

The instrumented production encode and route methods must both run, and restore even on failure. Fresh images and normalized proprio must equal the stored expert inputs. Repeated learned inference must match exactly. Every observation, reference, valid mask and oracle label is hashed. Before/after model and manifest hashes must remain stable; cross-model comparison verifies actual input hashes. A15-minute supervisor stops only its own process groups. No platform shutdown, model transfer, checkpoint selection, or independent test is performed.

Interpretation: improved oracle MSE makes semantic accuracy a plausible repair target; unchanged or worse MSE suggests that replacing these labels alone is insufficient and may expose an interface or distribution mismatch. Neither outcome isolates all causes or establishes online performance. Subsequent training changes require their own recorded protocol and complete matched CF evaluation.
