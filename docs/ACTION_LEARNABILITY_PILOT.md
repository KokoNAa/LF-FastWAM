# Action learnability pilot

The complete deployed-action200 experiment reaches25% ten-task macro CF with ERAF+FG, below its current no-ERAF control33.33% and strongest historical control35%. All five new tasks remain0/3. Fixed-state diagnostics also show worse initial expert action fit, including on selected training scenes. A local gradient diagnostic does not establish universal interference.

Before another full experiment, test actual optimization on one train scene per kind for each of cup and pill. Deterministic existing selector yields one ordinary initial observation and two corrective observations (failure start and middle), plus two heldout scenes per kind. No evaluation result or policy success filters the selection.

Six pilots share the current audited ERAF+FG final200 checkpoint: initial-only, correction-only, and balanced for each task. Each takes64 actual FP32-master AdamW steps at the current action-LoRA3e-6/interface3e-5 rates. Initial-only assigns mass1 to the initial row. Correction-only assigns1/2 to each correction row. Balanced assigns1/2 to initial and1/4 to each correction. There is no retention or source-language difference term in this deliberately simplified learnability objective. All receive the target instruction and real expert references. Gradients traverse all10 production denoising steps, and supervise the24 executed actions. Semantic heads and backbone remain frozen.

Training noise420000+step is shared across observations/regimes. Evaluation uses two separate fixed noise seeds42 and1000042 at steps0,16,64, covering all9 selected observations per task and per-dimension errors. Heldout rows never enter optimization. The pilot compares state fit, with different compute/observation counts across regimes; it is not a matched module ablation or a CF comparison. It has no checkpoint selection and cannot establish the user goal.

The controller first requires the complete180-CF terminal verification, checks source process termination and actual source weight SHA, clean code, six free GPUs and1GiB free disk. Its maximum20-minute wall clock stops only its own processes. No platform shutdown. All updates exist only in process memory; no model or optimizer file is saved or downloaded. Journals, input hashes, actual step records, changed parameter names, optimizer bindings and all snapshots are retained. The existing strongest models stay intact.

Next decisions follow actual results: if isolated fit fails, investigate optimization or action representation; if isolated fit improves but balanced fit fails, investigate weighting and shared parameter interference; if both fit, investigate larger-data retention and closed-loop rollout shift. These are hypotheses, not precommitted causal conclusions from three observations.
