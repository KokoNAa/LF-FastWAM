# Balanced target training

The completed deployed-action200 four-arm CF experiment reaches25% ten-task macro CF with ERAF+FG, below the strongest historical35%. All five new tasks remain0/3. Six subsequent in-memory64-step learnability pilots show that the same architecture and rates can fit both initial and corrective cup/pill observations when their weights are balanced. Small heldout corrective improvements are much weaker than training improvements. These diagnostics do not establish CF success or isolate the only cause of failure.

This trial starts all four arms fresh from the same strongest R action policy. ERAF-on arms use the existing S1500 ordinary/FG semantic parents with audited zero-output action identity. It does not continue from the regressed deployed-action200 weights. No additional semantic training or architecture change is made.

Every200-step arm uses global batch12: four old-task target-CF teacher rows, four cup/pill ordinary initial target expert rows, and four cup/pill full corrective rows. FG-off arms replace the four corrective slots with ordinary target expert observations matched by task/domain and batch position, using FG metadata only. Task/domain, scene and frame sampling are deterministic and scene-balanced; no heldout row is optimized. There are800 initial draws (400/task),800 corrective/replacement draws (400/task), and800 old-CF draws (160/old task) per arm. Full corrective observations span complete expert correction trajectories, rather than only the failure start.

The explicit `balanced_target_rollout_v1` objective uses only target-language observations and actions. It supervises the24 executed actions after all10 production denoising steps, with full gradients. CF retention targets are actual same-noise R teacher outputs and carry coefficient4; initial expert and corrective/replacement targets carry coefficient1. There is no Correct teacher loss or source-language conditional-difference term. Thus this is a multi-factor recipe change inspired by the pilot, not a single-factor causal ablation. All four arms receive the same new recipe. Action-LoRA rate3e-6, ERAF-interface rate3e-5, seed42 and no language augmentation remain fixed. Semantic heads and backbone remain frozen. FP32 master optimizers and final weights are retained.

The new objective is bound into CLI, immutable resume contract, actual journals and checkpoint provenance. Switching objective on optimizer resume is forbidden by the existing immutable-contract check. Stage audits reconstruct the new sampler, check actual IDs/rank gradient norms, frozen tensors and optimizer companions. The cross-arm audit verifies1600 identical common examples plus800 matched corrective/replacement slots and target-only loss records. Existing objectives remain available unchanged.

The controller requires the completed source CF and learnability records, verifies actual input hashes and source process termination, preserves the strongest-policy/semantic-parent identity checks, and reserves measured full model/optimizer output sizes plus1GiB. Four200-step trainings are followed by stage and paired audits, actual final weight hashes, unchanged180CF rollouts, comparison against all29 current and historical methods, and post-evaluation hashes. Only the final200 checkpoint is registered; no intermediate selection. The established strict burger slot supplement remains. The independent test remains unused until actual candidate superiority is established and selection is frozen.

Storage preparation losslessly compacted14 retired checkpoints on the server, verifying full tensor/metadata reconstruction before unlinking original serialization. Its receipt lists every path/hash and the retained common full base. Current A weights/optimizers, R strongest200, Q bestFG200, S parents and all optimizer states remain full. No model payload was transferred to the Mac. The operator deadline stops only owned processes; the platform stays on until the user goal is actually achieved.
