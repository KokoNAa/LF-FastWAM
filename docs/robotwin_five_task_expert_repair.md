# 五任务专家动作与 FG 改进实验

2026-09-08。目标是验证五任务宏平均 CF 的 ERAF+FG > ERAF > no-eraf，尚未实现。本实验不改变任务、成功判据、相机、动作执行窗口或对照模型定义。

## 已确认的训练错位

上一轮 balanced-target200 的正式测评为 no-eraf 121/200、ERAF 116/200、ERAF+FG 115/200。其实际采样审计每组共 2400 个样本：800 个旧五任务保持样本（每任务160），800 个杯子/药瓶初始专家样本，800 个杯子/药瓶 FG 或普通专家替代样本。最后200步没有向当前五任务直接提供新的 FG 动作监督。

保持样本的训练目标是同噪声的旧策略十步去噪输出，权重4；并非缓存中的专家动作。因此当前五任务主要受“保持旧行为”约束。数据覆盖和蒸馏目标是有代码、实际采样审计支持的问题；它们是否是性能退步的主因仍需实验验证。更早的语义训练用过 FG，不能声称整个训练路径从未接触这些任务的 FG。

现有、哈希绑定的缓存已经包含左放置与排序各48个训练纠错场景、各6个留出纠错场景；这批记录早于本轮正式测评。本轮600条正式结果只用于诊断，场景不回灌训练。后续正式测试必须重新留出新场景。

## 新对照设计

三组从同一个 R 动作适配器初始化。ERAF 两组保留各自既有的普通/FG语义父模型；上机前直接逐张量核对三组动作及视频适配器相同，并核对语义父模型的零输出身份报告。此次不继续训练语义头，video LoRA保持冻结。

每组200个 optimizer steps、global batch12、seed42、action LoRA学习率3e-6、ERAF接口学习率3e-5。每步：

- 4个五任务旧策略保持样本，权重由4改为1。
- 4个五任务真实目标专家动作样本，各任务均衡，权重1。
- 4个左放置/排序完整纠错样本；FG-off两组用同任务、同域、同轨迹相对区间的普通专家样本替代，权重也为1。

普通专家和FG数据均衡抽取轨迹前、中、后三段，避免后半程曝光不足。“三段”是录像时间区间，不是物理阶段标签或预测阶段。三组共同样本和FG替代槽位逐项匹配；FG-off只使用纠错元数据安排槽位，不读取纠错图像或动作。

使用实际十步去噪器的最终24步动作损失，梯度贯穿全部十步。目标专家监督直接对真实动作，教师保持单独记录。没有目标状态oracle输入、测试场景训练、训练后手动改写成功率或削弱对照。

这是一轮针对五任务的训练方案比较，数据任务、保持权重和时间采样一起改变；不能把相对上一轮的任何增益全部归因于单一改动。三组之间保留同预算对照来评估模块组合。

## 执行与验收

`scripts/run_robotwin_five_task_repair.py` 在服务器数据盘创建新目录，使用5卡（no-eraf一张、ERAF两张、ERAF+FG两张）。先用 `--steps 2` 做独立上机冒烟及实际权重/采样审计；冒烟权重不进入正式200步训练。

200步三组全部完成并通过逐样本、参数冻结和optimizer绑定审计后，再生成每任务12个新开发场景。训练、历史开发和已使用正式场景全部排除；双专家须从相同物理初态完成各自目标。完整180回合评测后报告三组CF、夹起及放置诊断。开发集出现排序也不标记目标完成。

只有开发评测支持改进才冻结三组模型，在另外每任务40个新场景上进行正式比较。五任务、每任务等权和原始判据保持不变。报告配对新增/丢失成功与样本不确定性；不通过反复更换测试种子寻找所需排序。

控制器只在绝对截止时间终止自身进程，不关平台实例。模型、优化器、视频全部留在服务器数据盘。本地仅保留代码和结果文本。之前被用户暂停的 trajectory-controls800 不恢复。
